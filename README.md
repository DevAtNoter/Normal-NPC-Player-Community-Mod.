# Normal NPC Player (NNP)

Normal NPC Player (NNP) is a Minecraft mod for Minecraft 1.20.1 that adds player-like NPCs to the game.

## About

NNP aims to provide NPCs that behave more like actual Minecraft players, including player-like behavior, interaction, combat, movement, and AI-driven systems.

## Minecraft Version

* Minecraft 1.20.1
* Forge
